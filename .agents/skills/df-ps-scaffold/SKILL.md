# Choose a df-ps item skill

Use this skill when the user asks for an item generated by `df-ps` and the item type is not yet clear. Once clear, use the matching focused skill below; do not duplicate its item-specific prompts.

| Requested item | Skill |
| --- | --- |
| Plan a multi-file source change and approve its scaffold mapping first | `$generate-new-source-file` |
| Initialize or inspect scaffold configuration | `$df-ps-initialize` |
| Bounded context | `$df-ps-bounded-context` |
| Aggregate or repository | `$df-ps-aggregate` |
| Domain error or error namespace | `$df-ps-error` |
| Domain service | `$df-ps-domain-service` |
| Application command | `$df-ps-command` |
| Application query | `$df-ps-query` |
| Application port / adapter | `$df-ps-application-port` |
| Application use case | `$df-ps-use-case` |
| Handlers-REST endpoint | `$df-ps-rest-endpoint` |
| React page | `$df-ps-react-page` |
| React widget | `$df-ps-react-widget` |

For a request that clearly names a type, prefer invoking that skill directly. For an end-to-end feature requiring several item types, invoke the relevant skills in dependency order and inspect each generated result before proceeding.

All item skills share [common-workflow.md](references/common-workflow.md), which covers project discovery, naming, interactive operation, collision handling, tests, and recovery. Read it along with the selected item skill. Version-specific implementation caveats are in [generator-2.6.0.md](references/generator-2.6.0.md).
